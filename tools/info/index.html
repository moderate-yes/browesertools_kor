자주 묻는 질문

단숨은 무료인가요?

네. 현재 제공되는 변환 및 계산 기능은 회원가입 없이 무료로 사용할 수 있습니다.

입력한 개인정보를 저장하나요?

일반 계산과 텍스트 처리는 브라우저 안에서 실행되며 입력 내용은 별도로 저장하지 않습니다.

환율은 어떤 기준인가요?

최신 영업일 기준환율을 사용하며 실제 환전 시 적용되는 수수료와 우대율은 포함하지 않습니다.
