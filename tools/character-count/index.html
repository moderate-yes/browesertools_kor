글자 수와 단어·줄·바이트를 바로 확인하세요

자기소개서, 상품 설명, SNS 게시글처럼 분량 제한이 있는 글을 붙여 넣으면 공백 포함과 제외 글자 수를 구분해 계산합니다. 한글을 포함한 UTF-8 바이트 수도 함께 제공합니다.

사용 방법

  1. 확인할 문장을 입력창에 붙여 넣습니다.
  2. 글자 수 확인 버튼을 누릅니다.
  3. 공백 포함·제외, 단어, 줄, 바이트 결과를 용도에 맞게 사용합니다.

자주 묻는 질문

공백 포함 글자 수와 제외 글자 수가 다른 이유는 무엇인가요?

공백 포함 값은 띄어쓰기와 줄바꿈을 포함하고, 공백 제외 값은 모든 공백 문자를 뺀 글자만 계산합니다.

한글 한 글자는 몇 바이트인가요?

UTF-8에서 일반적인 한글 음절은 3바이트입니다. 영문과 숫자는 보통 1바이트입니다.

입력한 글이 서버에 저장되나요?

아닙니다. 글자 수 계산은 사용자의 브라우저 안에서 처리되며 입력 내용은 별도로 저장하지 않습니다.
