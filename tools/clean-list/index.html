사용 방법

  1. 정리할 명단이나 목록을 입력창에 붙여 넣습니다.
  2. 명단 정리 버튼을 누릅니다.
  3. 정리 전·후 개수와 제거된 중복 수를 확인하고 결과를 복사합니다.

아닙니다. 처음 나타난 항목의 순서를 그대로 유지합니다.
